# CleanTempMail-Bot-Made-by-Yaelahto
Bot Python otomatis untuk membuat alamat email sementara (disposable email) dan melakukan scraping kode OTP atau tautan verifikasi secara real-time.  Proyek ini dirancang untuk mempermudah otomatisasi pembuatan akun (botting), QA testing, pengujian pendaftaran pengguna, serta menghindari penggunaan email pribadi.
